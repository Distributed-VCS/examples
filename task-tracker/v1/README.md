# Task Tracker 

A tiny, dependency free task tracker used as the exmple project in 
dvcs's tutorial and demo script.
not a real product - just enough substance to make the git workflow
demo mean something.

## Files
- `index.html` - page structure and the task list markup 
- `style.css` - layout and color 
- `app.js` - add/complete/remove task logic, persisted to `localStorage`
